*Originally published on [ashwch.com](https://ashwch.com/all-tools-should-now-have-two-users.html).*

In the article’s 24-day sample, agents ran 2,686 Dev Center commands on Ashwini’s laptop. The lesson wasn’t to build a separate tool for agents: it was to give them the same services, terminals and state that engineers use.

The full post walks through the false starts, app and CLI demos, cold-start discovery experiments, and Courage’s headless preview workflow. It also connects the same design principles to local-ci-runner.
